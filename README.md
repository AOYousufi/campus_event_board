# Campus Event Board

## Overview
Campus Event Board is a web application that allows students to **create, view, edit, delete, filter, and sort campus events**.  
The goal is to help students see what is happening on campus and share events easily.

This project is built as part of a collaborative project build.

---

## Tech Stack
- **Frontend:** React (Vite)
- **Backend:** Node.js with Express
- **Database:** PostgreSQL
- **Language:** JavaScript

---
